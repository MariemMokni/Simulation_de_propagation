# Simulation de propagation d'épidémie

Ce projet simule la propagation d’une épidémie sur une grille en utilisant plusieurs approches (séquentielle, OpenMP, MPI et CUDA).

## Rapport du projet
👉 [Télécharger le rapport PDF](rapport.pdf)

## Technologies utilisées
- C++
- OpenMP
- MPI
- CUDA

## Objectif
Étudier les performances des différentes approches de calcul parallèle.
